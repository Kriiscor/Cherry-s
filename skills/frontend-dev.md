# 🎨 Skill : Frontend Dev (NutriVision AI)

## Directives Frontend
1. **Composants `shadcn/ui`** : Utiliser exclusivement les composants de `@/components/ui/` pour maintenir l'homogénéité visuelle.
2. **Accessibilité & Responsive** : Convoir Mobile-First (Dialogs sur Desktop $\rightarrow$ Drawers sur Mobile).
3. **Formulaires & Validation** : Utiliser `react-hook-form` avec les resolvers `zod`.
4. **Gestion d'état serveur** : Privilégier TanStack Query / React Query pour le requêtage et l'invalidation de cache.
