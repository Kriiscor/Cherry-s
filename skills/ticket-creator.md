# 📝 Skill : Ticket Creator

Ce skill permet de rédiger des tickets techniques rigoureusement structurés selon le modèle suivant :

```markdown
# [TICKET-ID] scope: Titre du ticket

## 1. 🎯 Contexte & Objectif Métier
- **User Story** : En tant que... je souhaite... afin de...
- **Règles de gestion** : Règles métier.

## 2. ✅ Critères d'Acceptation (Definition of Done)
- [ ] Critères de réussite fonctionnels et techniques.

## 3. 🛠️ Spécifications Techniques par Périmètre
- **Base de Données** : Schémas, migrations, RLS.
- **Backend & API** : Routes, validation Zod, Rate Limiting.
- **Frontend** : Composants shadcn/ui, Hooks, UI feedback.

## 4. 🧪 Scénarios de Validation & Tests
- Scénarios nominaux, tests de sécurité et d'erreur.
```
